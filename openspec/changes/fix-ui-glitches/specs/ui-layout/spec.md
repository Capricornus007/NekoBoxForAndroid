# Spec Delta

## Purpose

定义 ThroneForAndroid 界面布局与系统栏处理的可验证行为：空状态内容的居中规则、首页配置切换栏的尺寸规则，以及沿用 T4A v1.x 布局的界面顶部状态栏空间在滑动中保持固定的规则。

## ADDED Requirements

### Requirement: 空状态提示块屏幕居中
首页配置列表在没有可显示的配置时展示的空状态提示块（图标、标题、说明文字及其附属按钮）MUST 在整个屏幕可视区域内几何居中（水平与垂直均居中），MUST NOT 因滚动容器视口拉伸或为底部悬浮控件预留的不对称内边距而偏向屏幕上部；当提示内容超出屏幕高度时 MUST 仍可滚动查看全部内容。

#### Scenario: 空分组显示居中提示
- **GIVEN** 当前分组中没有任何配置，首页显示空状态提示块
- **WHEN** 用户观察提示块在屏幕上的位置
- **THEN** 提示块的视觉重心位于屏幕水平与垂直中心附近，不在屏幕上部

#### Scenario: 订阅分组为空时同样居中
- **GIVEN** 当前分组是尚无配置的订阅
- **WHEN** 首页显示订阅空状态提示块（含"更新订阅"按钮）
- **THEN** 提示块（含按钮）整体在屏幕内居中显示

#### Scenario: 提示内容超出屏幕高度
- **GIVEN** 屏幕高度很小或字体缩放很大，提示块内容高度超过可视区域
- **WHEN** 用户上下滑动
- **THEN** 提示内容可滚动完整查看，不被截断

### Requirement: 配置切换栏尺寸
首页用于切换配置分组的标签栏 MUST 比默认标签栏更矮（高度约 40dp，"稍微小一点"的观感），其标签文字 MUST 比默认标签文字更大（约 16sp），且该调整 MUST 仅作用于首页配置切换栏，不影响应用内其他标签栏、按钮与对话框按钮的文字尺寸。

#### Scenario: 标签栏高度与字号
- **WHEN** 用户打开首页且存在至少一个配置分组
- **THEN** 分组标签栏呈现约 40dp 的高度与约 16sp 的标签文字，观感为"栏更矮、字更大"

#### Scenario: 不波及其他控件
- **WHEN** 用户查看应用内按钮、对话框按钮及其他标签栏
- **THEN** 其文字尺寸与改动前一致

### Requirement: legacy 界面状态栏空间固定
分应用代理、应用列表选择、规则集选择等沿用 T4A v1.x 折叠头部布局的界面，其顶部为状态栏预留的空间 MUST 由界面自身的静态布局/inset 内边距固定填充，MUST NOT 在列表 fling（用力快速滑动）或其他滚动过程中出现该空间随之下滑、脱离或露出窗口背景的现象。

#### Scenario: 用力滑动列表时顶部不动
- **GIVEN** 用户打开分应用代理界面，应用列表可滚动
- **WHEN** 用户在列表上用力快速上滑或下滑（fling）
- **THEN** 顶部状态栏区域始终保持界面主题色填充，不出现空白/窗口背景，头部不随之下移

#### Scenario: 其他 legacy 界面同样固定
- **GIVEN** 用户打开应用列表选择或规则集选择界面
- **WHEN** 用户对列表执行 fling
- **THEN** 顶部状态栏空间同样保持固定，不随滑动下移

#### Scenario: 折叠头部滚动不受影响
- **GIVEN** 分应用代理界面的头部（模式开关、搜索框）处于展开状态
- **WHEN** 用户缓慢滚动列表使头部折叠、再反向滚动展开
- **THEN** 头部折叠/展开行为正常，状态栏空间在折叠全过程中保持主题色填充
